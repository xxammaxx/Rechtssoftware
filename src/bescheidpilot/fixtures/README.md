# Fixtures

Only synthetic or explicitly reviewed anonymized fixtures may be stored here.

Do not commit:

- real notices
- names, addresses, case numbers, account data, signatures, or barcodes
- unreviewed OCR output
- screenshots containing personal data
- legal documents without a documented right to use them

Each future fixture requires provenance, expected structured output, reviewer, and deletion/retention notes. The first fixture is tracked in GitHub Issue #17.
