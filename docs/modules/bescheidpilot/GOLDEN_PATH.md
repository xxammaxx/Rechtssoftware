# Golden Path

## Zielablauf

1. Nutzer wählt lokalen Text oder später ein lokales Dokument.
2. Eingabe wird ausschließlich im lokalen Prozess verarbeitet.
3. BescheidPilot erzeugt Frist- und Handlungskandidaten.
4. Jeder Kandidat zeigt Fundstelle, Methode und Unsicherheit.
5. Ein lokaler Entwurf nutzt nur überprüfbare strukturierte Fakten.
6. Nutzer prüft Fundstellen und bearbeitet oder bestätigt den Entwurf.
7. Export wird explizit ausgelöst und lokal gespeichert.
8. Es erfolgt keine automatische Übermittlung.

## Abbruchbedingungen

- Netzwerkzugriff wird versucht.
- Fundstelle fehlt.
- Frist oder Handlung wird als sicher dargestellt, obwohl Unsicherheit besteht.
- Human Review kann umgangen werden.
- Exportziel ist nicht lokal oder nicht vom Nutzer gewählt.
- Logs enthalten Fixture-Marker oder sensible Inhalte.

## MVP-Evidence

Der Golden Path gilt erst als bewiesen, wenn ein synthetischer Fixture-Test offline durchläuft und die Ausgabe gegen einen überprüften Erwartungsdatensatz verglichen wurde.
